# ADR 0005: Web V1 默认采用自动目标弦匹配

## 状态

Accepted

## 背景

调音器在交互上有两种常见思路：

- 用户先手动选中目标弦，再开始调
- 系统根据检测结果自动匹配最近的目标弦

对当前项目来说，目标用户包含大量新手。若首版要求用户先理解每根弦并手动选择，会增加使用门槛。

## 决策

Web V1 默认采用自动目标弦匹配：

- 用户拨哪根弦，系统尽量自动匹配最近目标弦
- 页面同步高亮当前目标弦

V1 不强制提供手动锁弦功能，但允许后续版本补充。

## 原因

- 降低新手首次使用门槛
- 更符合“打开即用”的产品定位
- 可以减少页面控制项数量，保持界面聚焦

## 影响

正面影响：

- 主流程更直接
- UI 更简洁
- 更适合移动端

负面影响：

- 相邻音或不稳定检测时，可能出现目标弦来回跳转
- 进阶用户可能希望更精确地锁定某根弦

## 后续

- 若真实测试中跳转问题明显，在 V1.1 评估加入手动锁弦

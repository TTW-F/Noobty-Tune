# ADR 0001: Web V1 产品范围锁定为六弦吉他标准调弦

## 状态

Accepted

## 背景

`Noobty Tune` 当前处于需求分析和设计阶段，目标是先做一款 `Web` 端可用的吉他调音器，稳定后再考虑桌面端和 App。

如果首版范围过大，会同时引入以下复杂度：

- 多乐器支持
- 多种调弦方式
- 更复杂的目标弦匹配逻辑
- 更复杂的交互和教学说明
- 更大的测试矩阵

当前项目的核心风险并不在功能不足，而在：

- 浏览器麦克风权限流程
- 低频识别稳定性
- 新手是否理解反馈
- 手机和桌面浏览器的基本可用性

## 决策

Web V1 范围锁定为：

- 六弦吉他
- 标准调弦 `E2 A2 D3 G3 B3 E4`
- 浏览器麦克风输入
- 单弦实时识别
- 偏高 / 偏低 / 已调准反馈

V1 明确不包含：

- 多乐器
- alternate tunings
- 多弦同时识别
- 账号和历史记录
- 云端音频处理

## 原因

- 先验证单一核心场景，降低失败风险
- 控制工程复杂度
- 缩小测试范围
- 让后续多端扩展建立在稳定核心能力之上

## 影响

正面影响：

- 需求清晰
- 技术验证集中
- UI 和测试更容易收敛

负面影响：

- 首版能力不够丰富
- 无法覆盖更高级用户的多调弦需求

## 后续

- 若 V1 稳定，可在后续版本增加手动选弦、参考音和其他调弦方式

# Noobty Tune Web V1 里程碑定义

## 1. 目标

定义 Web V1 的阶段性交付标准，避免“做了很多事但无法判断是否前进”。

## 2. 里程碑

### M1 原型启动

完成标准：

- 前端工程可运行
- 页面能完成开始调音入口
- 麦克风权限流程跑通

### M2 检测验证

完成标准：

- 原型能从麦克风获取可处理音频
- 至少一条检测路线可稳定输出频率候选
- 完成低 E 到高 E 的首轮验证

### M3 核心闭环

完成标准：

- 页面能展示目标弦、检测音、偏差方向和成功状态
- 主流程可从开始调音走到已调准

### M4 可用版本

完成标准：

- 桌面和移动端均可完成核心流程
- 权限失败、弱信号、噪声场景有合理反馈
- UI 具备基本可理解性与可访问性

### M5 发布候选

完成标准：

- 测试计划主要场景通过
- P0 缺陷关闭
- 已知限制已记录

## 3. 节奏建议

建议按“风险优先”推进：

- 先过 M1 和 M2
- 再做 M3 的完整产品闭环
- 最后打磨 M4 和 M5

## 4. 当前判断

当前项目状态属于：

- `Pre-M1`

因为目前已经具备完整的分析、需求、设计、测试和 ADR 文档，但尚未开始实现与原型验证。

# Docs Backup Snapshot (2026-04-13)

该目录用于保存文档结构迁移前的历史文件快照，避免迁移过程中的误删风险。

## 目的

- 提供迁移前文件的可回滚副本
- 支持问题排查与历史比对
- 防止主目录出现新旧文档并存

## 使用约束

- 本目录文件仅用于备份与审计，不作为主文档入口
- 不要在主文档中引用本目录下文件
- 不要在本目录继续演进内容

## 恢复方式（仅在紧急场景）

1. 先确认目标 canonical 路径不可用或内容损坏
2. 从本目录复制所需文件到目标 canonical 路径
3. 完成后重新执行全量链接校验
4. 在迁移计划文档中记录恢复原因与操作记录
